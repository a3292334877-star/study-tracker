# 学习记录 · Study Tracker

记下每天学了什么，看见自己的积累。零依赖纯静态 PWA，原生 ES Module + CSS，无构建、无 npm 包，数据只存在浏览器本地。

- 版本：v1.6
- 项目路径：`D:/DeepseekH/project/study-tracker/`

## Android 应用（APK）

项目同时打包为真正的 Android 应用：**`study-tracker.apk`**（183,000 字节，约 179 KB，versionCode 5 / versionName 1.6，minSdk 24 / targetSdk 34，arm64 与 x86_64 通用）。

- 壳工程：`android/`（aapt2 + javac + d8 + apksigner 手动构建，无 gradle）
- 构建脚本：`_tools/build-apk.py`；签名密钥 `android/build/release.keystore`（pass `xuexijilu123`）
- 壳是 WebView + 本地 assets（`https://appassets.local` 拦截加载，离线可用，无需任何权限）
- 原生能力桥 `window.AndroidApp`：主题同步状态栏、Haptic 振动、导出 JSON 到下载目录、文件导入、返回键关弹层、**海报 / 打卡卡存相册**（`saveImage`）、**静默备份落盘**（`saveBackupQuietly`）、**计时常驻通知**（`updateTimerNotification` / `stopTimerNotification`）、通知权限查询与跳转（`notifPermissionGranted` / `openNotifSettings`）
- 同步与校验：`_tools/sync-www.py` 把 web 源码镜像进 `android/assets/www`，`_tools/_verify_apk.py` 再回读 APK 断言关键字符串确实在包里
- 安装：把 `study-tracker.apk` 传到手机点开即可（需允许安装未知来源应用）

## 一条记录是什么

产品核心是**记内容**，不是掐时间。一条记录由五部分组成：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 科目 | 给记录分类，统计时按科目汇总 | 是（需先有科目） |
| 学了什么 `title` | 一句话描述这次学了什么，最长 40 字 | **是** |
| 标签 `tags` | 自由标签，可多个，用于跨科目归类 | 否 |
| 时长 `minutes` | 分钟数，**可以为 0** | 否 |
| 心得笔记 `note` | 重点、疑问、错在哪，最长 500 字 | 否 |

> 只记内容、不记时长，也是一条完整记录。时长留空即按 0 处理，列表里显示「未计时」。

**标签规则**（`store.js` 的 `normTags()` 统一归一）：自动去掉开头的 `#`、单个不超过 12 字、同一条内去重、最多 6 个。标签会进入搜索索引，也能在学习记录页按标签筛选。

## 功能清单

### 今日 `#/home`

- 今日学习时长 hero + 每日目标进度条（达成后显示「已达成」）
- 「+ 记一笔」按钮
- 三格数据：连续记录天数 / 近 7 天时长 / 今日记录条数
- 「今天学了什么」记录卡列表，点任意一条即可修改
- 今日任务：添加、勾选完成、删除

### 学习记录 `#/log`（核心页）

- 全部记录按天分组的时间线，倒序排列，每天显示条数与合计时长
- **分页加载**：每页 50 条，滚到底部出现「加载更多 · 还有 N 条」，点击**追加**渲染（不重建整张列表，滚动位置不跳），全部加载完显示「已显示全部 N 条」
- 计数行显示全量口径：「共 N 条 · 合计 X」；有搜索/筛选时显示「找到 N 条 · 合计 X」（时间范围切换也算筛选，无结果为「找到 0 条」）
- **编辑/删除后列表不重建**：改完一条记录，当前筛选条件、搜索词、已加载的页数与滚动位置全部保留
- 搜索框：搜学习内容、笔记、科目、标签，输入 **130ms 防抖**后即时过滤，命中词用 `<mark>` 高亮
- 筛选：时间（全部 / 近 7 天 / 本月）+ **科目 chips** + **标签 chips**，三种条件可叠加；无结果时给「没有符合条件的记录」+「清除筛选」
- 记录行显示 `#标签` chip
- 点任一条打开编辑（可改科目、内容、标签、时长、日期、心得，或删除）
- **删除可撤销**：删完底部弹出 8 秒撤销条（「已删除「标题」」+「撤销」），点「撤销」原样放回（保留原 id 与时间）
- 底部「+ 记一笔学习」

### 记一笔表单

字段顺序固定为：

1. **科目** chips（点选）
2. **学了什么** —— 必填，`maxlength=40`
3. **标签**（可选）—— 输入后实时生成可点 × 删除的小 chip
4. **时长**（分钟）—— 可留空（=0），快捷按钮 15 / 30 / 45 / 60 / 90
5. **日期** —— 可选历史日期，不能选未来
6. **心得** —— 可选，`maxlength=500`
7. **常用模板** —— 点模板 chip 一键填入科目 / 内容 / 时长 / 标签；「＋ 存为模板」把当前填写内容存下来（最多 20 条，按最近使用排序，表单里最多展示 6 个）

底部导航中间的「+ 记一笔」在**任何页面**都能唤起这个表单。

表单顶部还有 **「⚡ 复制上一条」**：一键带出上一条记录的科目、内容、标签、时长与心得再改，适合连着记同一类学习（测试脚本会断言按钮出现且字段完整带出）。

### 计时 `#/timer`（辅助工具）

- 专注：正计时（记录真实专注时长，可随时结束），也可切倒计时并选 15 / 25 / 45 / 60 分钟预设
- 短休息 5 分钟 / 长休息 15 分钟：倒计时，结束**不计入学习时长**
- 计时状态写入 localStorage，刷新页面不丢失
- 到点用系统通知提醒（需授权）
- **Android 端常驻通知**：计时进行时通知栏常驻显示「专注 · 00:12 · 计时中」/「已暂停」，暂停、重置、结束都会更新或清除；「我的 → 计时结束提醒」显示「已开启 / 未授权」，未授权时点一下直接跳系统通知设置
- 计时结束落库后，自动弹出「这次学了什么？」让你补一句内容

### 统计 `#/stats`

- 范围切换：本周 / 本月 / 全部
- **周期对比行**：本周 vs 上周（本月对上月；「全部」对最近 30 天 vs 此前 30 天），显示百分比涨跌；上一周期为 0 时显示「无记录」且不给百分比，持平时显示「与上周持平」
- 指标格：当前周期时长 / 记录条数 / 学习天数 / **最长连续** / **最佳单日（月日 · 时长）**
- 每日趋势柱：本周按「本周一到周日」，点柱子查看当天全部记录；**本月 / 全部只画最近 14 天**（避免 28 根柱在 390px 宽度下横向溢出）
- 科目分布：每个科目的时长 + 记录条数
- 最近记录 5 条
- 记录热力：最近 8 周，共 56 格，可点开当天
- **学习周报**：一键生成按内容自适应的长图海报（累计时长 / 记录数 / 学习天数 / 日均 / 周目标达成 / 科目分布 / 本周学了），可「保存图片」到相册（Android 存 `Pictures/学习记录`）或「复制文字」粘贴分享
- **🎴 打卡卡**：把连续打卡天数做成一张 Canvas 分享卡（连续天数大数字 / 最长连续 / 累计学习 / 最近 7 天迷你柱），可保存图片，文件名 `打卡卡-连续N天.png`（Android 存相册，网页版走下载）

### 科目 `#/subjects`

- 列表行显示「最近：xxx」+「N 条」，附近 7 天时长条
- **每周目标**：给科目设每周小时数，行内显示「本周 5h22m / 目标 3h · 100%」，列表底部汇总「近 7 天共 xx · n/m 个科目达成周目标」
- **归档**：不删任何数据、只从主列表收起（记录与统计全部保留），列表底部出现「已归档 n」分组，随时可「恢复使用」
- 新建 / 编辑 / 删除（emoji + 颜色；删除会连同该科目下的记录一起删）
- 点开科目详情：3 个 stat（累计时长 / 学习记录 / 学习天数）+「学过什么」最近 10 条，可点进编辑

### 我的 `#/me`

| 分组 | 内容 |
| --- | --- |
| 学习档案 | N 条记录 · N 天 · 累计时长 |
| 目标 | 每日目标、默认专注时长 |
| 外观 | 主题（跟随系统 / 浅色 / 深色）、每周起始日 |
| 应用 | 添加到主屏幕、计时结束提醒（Android 下显示「已开启 / 未授权」并可跳系统通知设置） |
| 工具 | 科目管理（进入 `#/subjects`）、专注计时（进入 `#/timer`） |
| 数据 | **自动备份**开关、**立即备份**（可命名）、**备份快照**（N 份，可恢复 / 删除）、导出 JSON、导入 JSON（合并或覆盖）、**移除示例数据**（仅在还有示例数据时出现）、清空所有数据 |

数据区细节：

- **自动备份**：每天首次打开应用时若数据有变化就写一份「每日自动」快照；同一天不会重复写入
- **立即备份**：可以起个名字（留空则用「手动备份」），存成一份独立快照
- **备份快照**：最多保留 **7 份**，列表显示「名称 · 时间 · N 条记录」，每份都能恢复或删除；恢复前会先自动存一份「恢复前保护」，误点也能回退
- **导入**：选文件先校验结构，通过后让你选「合并到现有数据」（科目同名复用、记录按 id 去重、todos 按文本去重）或「覆盖全部数据」（覆盖前自动存一份「导入前保护」，合并也一样先存）
- **清空所有数据**：清空前自动存一份「清空前保护」快照，误清还能恢复
- **写盘失败会明说**：浏览器存储写不进去（配额满 / 隐私模式）时，顶部出现红色提示条「存储空间已用满，最近的修改没能保存」，并给一个直达「我的 → 导出数据」的链接，不再只是控制台里一条 warn

页脚显示「学习记录 v1.6」。

## 本地运行

在项目目录下起一个静态文件服务器：

```bash
cd D:/DeepseekH/project/study-tracker
python -m http.server 8123
```

浏览器打开 <http://127.0.0.1:8123>。

也可以用项目自带的服务器脚本：

```bash
node _tools/server.mjs "D:\path\to\study-tracker" 8123   # 根目录用绝对路径，相对路径会被判 403
```

> **必须用 http 打开。** 直接双击 `index.html` 以 `file://` 协议访问时 ES Module 与 Service Worker 都受限，离线缓存和「添加到主屏幕」都会失效。

## 安装到手机主屏（PWA）

1. 确认手机与电脑在同一局域网；
2. 手机浏览器访问 `http://<电脑IP>:8123`（如 `http://192.168.1.10:8123`）；
3. 安装：
   - **Android Chrome / Edge**：右上角「⋮」菜单 →「安装应用」或「添加到主屏幕」
   - **iOS Safari**：分享按钮 →「添加到主屏幕」
   - 支持原生安装弹窗的浏览器，也可在「我的 → 添加到主屏幕」里点「立即安装」
4. 装好后从主屏图标启动，全屏运行、无地址栏，离线也能打开。

> iOS 只有 Safari 支持添加到主屏幕，微信等内置浏览器需先「用浏览器打开」。

## 数据存储说明

- 所有数据仅保存在**当前浏览器的 localStorage**，不上传任何服务器，不跨设备同步。
- 主数据键名：`study-tracker/v1`（科目、记录、标签、模板、任务、设置）
- 计时器状态键名：`study-tracker/timer`
- 快照列表键名：`study-tracker/backups/v1`（最多 7 份，每份含名称、原因、时间与完整数据快照，`reason` 取值 `auto` / `manual` / `pre-restore` / `pre-import` / `pre-clear`）；v1.3 的单份快照 `study-tracker/backup-latest` 只用于一次性迁移，读到时自动并进新列表
- 损坏留档键名：`study-tracker/corrupt/<时间戳>`。主数据键解析失败时不会直接丢弃：先把原始字符串原样存进这个键，再尝试用最近一份可用快照恢复；恢复不了就从空数据起步，并在打开时弹 toast 说明（v1.6）
- Android 端额外落盘：海报 / 打卡卡图片 `Pictures/学习记录/`，静默备份 `getFilesDir()/backup/backup.json`
- **首次打开会写入示例数据**：4 个示例科目（高等数学 / 数据结构 / 英语 / 算法竞赛）和最近几周的示例记录（含今天），方便直接看到完整界面。示例数据都带 `demo` 标记，可以只删示例、保留自己写的：在「我的 → 移除示例数据」一键清掉，自己新增的记录 / 科目 / 任务 / 待办不受影响；在「我的 → 清空所有数据」清空后，也不再自动生成示例数据。
- 清理浏览器数据、换浏览器或用无痕模式，都会导致数据不可见。
- 备份与迁移：先在「我的 → 导出数据」保存 JSON，再在目标设备「我的 → 导入数据」恢复（可选合并或覆盖）。

## 技术栈

- 原生 JavaScript ES Module，无框架、无打包器、无第三方依赖
- 原生 CSS（自定义属性 + 明暗主题），v1.4 起按页面拆成 `css/parts/*.css` 分片
- hash 路由（`#/xxx`），单页应用，6 个视图
- Web App Manifest + Service Worker：离线缓存（页面网络优先，静态资源缓存优先 + 后台更新），缓存版本 `study-tracker-v11`
- Notification API：计时到点提醒；Android 壳用原生 `Notification` + `NotificationChannel` 常驻通知
- Canvas 2D 手绘周报海报与打卡卡（无第三方绘图库），Android 端经 MediaStore 存进相册
- 数据层：`localStorage`，单 store + 订阅驱动重渲染；列表分页由 `querySessions({offset, limit})` 承担，不再有硬上限；v1.5 起按天聚合（`dayBuckets()`）与排序结果都做了缓存，写入时失效、读取时重算一次，统计页 56 格热力图不再 56 次全表扫描
- 无障碍：弹层 `role=dialog` + `aria-modal` + 焦点陷阱（Tab 循环 / Esc 关闭 / 打开进焦点 / 关闭还原），toast 与 `#toast` 带 `role=status` / `aria-live=polite`，路由切换写入 `#sr-status` 供读屏播报，另有 `.sr-only` 与 `:focus-visible` 样式

`test7.mjs` 覆盖 v1.6 的数据安全链路：

- **写盘失败**：把 `Storage.prototype.setItem` 打桩成抛 `QuotaExceededError`，新增记录后必须出现 `#storage-warn` 提示条、含「存储空间」文案、带「去导出备份」链接，点关闭可收起；恢复正常写入后提示条自动收起，再失败又出现
- **示例数据隔离**：清掉 localStorage 重载回到示例态，写入一条自己的记录与待办后点「移除示例数据」，示例记录 / 科目被删、自己的记录与待办还在，行也随之消失
- **清空前保护快照**：`resetAll()` 后 `listBackups()[0].reason === 'pre-clear'`、名称为「清空前保护」，快照里记录数与清空前一致
- **导入前保护快照**：合并导入后 `backups[0].reason === 'pre-import'`
- **损坏恢复**：先把主数据键写成非 JSON 字符串，重载后数据从快照恢复、`study-tracker/corrupt/` 下留下原始内容、toast 含「恢复」

单独跑某个套件：

```bash
node _tools/server.mjs "D:\path\to\study-tracker" 8123   # test.mjs / test2~test5 需要先起服务器
node _tools/test6.mjs <项目根> <输出目录> "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
```

其余脚本参数相同，替换脚本名即可。套件支持用环境变量 `ST_PORT` / `ST_DBG` 指定静态服务端口与 CDP 调试端口（默认 8123 与 9333/9336/9338/9339/9341/9356，test6 自带 8126 服务器，test7 自带 8127）。每个套件结束时写一份 `result*.json` 并在有失败时以退出码 1 结束，输出目录用于存放截图与结果。

三个注意点（踩过坑）：

- **输出目录请用绝对路径**（如 `D:\...\_shots`）。Edge 拿到相对 `--user-data-dir` 会起不来调试端口，脚本只报 `no devtools` 就退出。
- **服务器根目录也必须是绝对路径**：`node _tools/server.mjs . 8123` 会被目录越界守卫判成 403，页面变成空白文档，套件随后报 `SecurityError: Failed to read the 'localStorage' property from 'Window'`；用 `run-all.mjs` 不会踩这个坑。
- 同一时刻只跑一个套件：各套件调试端口接近、`--user-data-dir` 也会互相锁（`run-all.mjs` 已串行）；若上次异常退出留下 headless Edge 占着端口，先结束残留进程再跑，否则 `/json/list` 会被旧浏览器应答、页面停在 `about:blank`。

Android 侧另有两层校验：

- `_tools/_verify_apk.py`：直接读 APK 里的 `classes.dex` 与 `assets/www`，断言 `saveImage` / `saveBackupQuietly` / `openNotifSettings` / `updateTimerNotification` 与前端新文案都在包里（防止「改了源码没同步就打包」）；
- `_tools/device.mjs`：通过 `adb forward` + CDP 连接模拟器/真机上的 WebView，直接执行脚本验证常驻通知、海报落盘、快照恢复等只有设备上才成立的行为，用法 `node _tools/device.mjs '<js>'`（以 `@` 开头时从文件读脚本）。

## 常见问题

**忘记开计时怎么办？**
不用管计时。在任何页面点底部中间的「+ 记一笔」，写下学了什么就行，**时长可以留空**。也可以在「统计」里点某一天的柱子、或点热力图格子，进入当天记录后「补记一条」。

**只记内容不记时长可以吗？**
可以。时长是可选项，留空按 0 处理，记录里显示「未计时」。产品默认就是「记内容优先」。

**双击 index.html 打开后页面空白？**
`file://` 下 ES Module 和 Service Worker 都受限。请按上文用 `http://` 方式访问。

**计时页从哪里进？**
底部导航没有计时 tab。从「我的 → 工具 → 专注计时」进入，或直接访问 `#/timer`。

**休息时间会计入学习时长吗？**
不会。只有「专注」结束时产生的时长会落库，短休息 / 长休息只用来休息。

**计时到点没有提醒？**
系统通知需要授权。在「我的 → 计时结束提醒」里开启；若已被拒绝，需要到浏览器的站点设置里手动允许通知。

**刷新页面计时器还在吗？**
在。计时状态实时写入 `localStorage`（键 `study-tracker/timer`），刷新或重开应用都会恢复。

**删错了记录还能找回来吗？**
能。删除后底部会留 8 秒撤销条，点「撤销」即可原样放回。超过 8 秒也可以从「我的 → 备份快照」恢复最近一份快照。

**标签怎么用？**
记一笔时在「标签」里输入（多个用逗号或空格分隔），会自动去 `#`、限 12 字、去重、最多 6 个。之后在「学习记录」页顶部点标签 chip 就能只看这一类记录，搜索也会命中标签。

**模板会不会越存越多？**
最多保留 20 条，按最近使用时间排序；表单里只显示最近用的 6 个，用不到的可以在模板 chip 上删掉。

**换手机 / 换浏览器后数据不见了？**
数据只在本机浏览器里。请先在旧设备「我的 → 导出数据」，再在新设备「我的 → 导入数据」。日常也可以打开「我的 → 自动备份」，每天都留一份快照，误操作后在「我的 → 备份快照」里点「恢复」就能回到某一次备份的状态。

**导入会覆盖现有数据吗？**
不会强制覆盖。选完文件会先校验结构，通过后由你选「合并到现有数据」（科目同名复用、记录按 id 去重、任务按文本去重）或「覆盖全部数据」；覆盖前会自动存一份「导入前保护」快照。

**周报海报 / 打卡卡存在哪？**
Android 应用里点「保存图片」会存到相册 `Pictures/学习记录/`，系统相册和文件管理器都能看到；网页版则走浏览器下载。打卡卡文件名是 `打卡卡-连续N天.png`。想直接发文字，用「复制文字」把排版好的周报贴到聊天窗口即可。

**备份快照会不会占很多空间？**
不会。最多保留 **7 份**，每份是压缩过的 JSON（通常几 KB），超出后最旧的一份自动淘汰；「每日自动」同一天不会重复写。Android 端还会另外静默写一份到应用私有目录 `backup/backup.json`。

**手机上打不开 `http://<电脑IP>:8123`？**
确认手机与电脑同一局域网、电脑防火墙放行 8123 端口，且服务器仍在运行。
